# AtlasQuarry 管理者マニュアル

## まず見る場所

- **今日**: 自分が次に進める仕事、期限超過、判断待ちの要望を確認する。
- **プロジェクト**: 進行中・完了・停止を切り替え、検索で目的のプロジェクトを絞る。
- **タスク**: 一覧とかんばんを切り替える。担当者・完了済み表示を「絞り込み」から変更する。
- **保存済みビュー**: 現在のプロジェクト、表示形式、担当者、完了済み表示を名前付きで保存する。URLコピーで共有もできる。
- **お知らせ**: 自分に関係する変更を確認する。開くと既読になる。

## メンバー管理

設定 → メンバーから、管理者権限を持つユーザーが招待、氏名変更、ロール変更、利用停止・再開を行う。自分自身の権限は変更できず、最後のownerを降格・停止する操作もできない。

## 監査ログ

設定 → 監査ログでは、操作者、日時、操作、対象、変更内容を確認する。要望のトリアージ、タスクの状態変更、権限変更など、判断の根拠を追跡する際に使用する。

## 要望の処理

1. 今日または要望一覧から未処理の要望を開く。
2. 判断待ちのものを選択し、まとめて「検討中にする」。
3. 採用する要望は詳細からタスクへ変換し、担当者と期限を設定する。

## 管理の原則

- 日常の入口は「今日」に固定し、全件確認はプロジェクト・保存済みビューから行う。
- 期限や担当者が決まっていないものを、無理にタスク化しない。
- 操作後に意図しない変更がないか、監査ログで確認できる状態を維持する。
